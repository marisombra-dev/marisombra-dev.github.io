Desktop Ethan

A personal desktop AI companion application.

Desktop Ethan is a locally operated desktop companion used by its owner. It combines realtime voice, local computer interaction, persistent project continuity, and an optional native Google Workspace connection.

Google Workspace access

When the owner explicitly authorizes Google access, Desktop Ethan may use Gmail, Google Calendar, and Google Drive APIs to carry out the owner's requests. The application uses OAuth authorization and does not ask for the owner's Google password.

The current Google connector is designed around bounded capabilities rather than unrestricted account control. Higher-risk actions are deliberately excluded unless they are separately implemented and reviewed.

Data handling

OAuth credentials and tokens are stored locally in the owner's private user configuration and are not published on this website or in the public source repository. Google user data is accessed only to respond to the owner's requests and is not sold or used for advertising.

For details, see the Desktop Ethan Privacy Policy.
